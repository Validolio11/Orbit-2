# Orbit 2

Windows-застосунок для швидкого запуску дій через радіальне меню. Наступник Orbit: та сама ідея «бічна кнопка миші → колесо біля курсора», але з новими типами дій, меню для окремих програм, статистикою, пошуком Ctrl+K, резервними копіями й оновленим дизайном з кольором акценту.

Orbit 2 — окремий застосунок і працює поруч із першим Orbit: має свій `Orbit2.exe`, свою папку налаштувань `%APPDATA%\Orbit 2`, свій інсталятор, запис у «Програмах» і завдання адміністратора. Під час першого запуску Orbit 2 сам переносить меню й налаштування з Orbit. Якщо перший Orbit ще працює, Orbit 2 попередить про це й запропонує закрити його, щоб бічна кнопка не відкривала два колеса.

## Що нового в Orbit 2

- **Дія «Клавіші»** — натискає будь-яку комбінацію (Ctrl+Shift+T, Alt+Tab, F5…) у програмі під колесом. Комбінацію можна просто натиснути в полі або вибрати з готових.
- **Дія «Текст»** — вставляє заготовлений фрагмент (підпис, адресу, шаблон відповіді). Попередній текст буфера обміну повертається.
- **Команди вікон** — закрити, згорнути, розгорнути вікно, наступний і попередній робочий стіл.
- **Меню для програм** — прив'яжіть меню до `photoshop.exe`, `chrome.exe` тощо (кнопка-скріпка біля вкладок меню). Над цією програмою колесо одразу відкриє потрібне меню.
- **Розумніше колесо** — у центрі видно назву дії під курсором, дуга показує відлік затримки наведення. Коліщатко миші гортає сектори, цифри 1–9 запускають дію за номером, праве клацання повертає на рівень вище.
- **Огляд** — справжня локальна статистика: запуски за сьогодні й тиждень, активність за 14 днів, найпопулярніші й нещодавні дії.
- **Ctrl+K** — командна палітра: знайти й запустити будь-яку дію, перейти на сторінку, виконати команду. Shift+Enter відкриває дію для редагування.
- **Резервні копії** — щодня перед першою зміною Orbit 2 зберігає копію меню (до 20 останніх). Відновлення в один клік, причому поточний стан теж зберігається.
- **Налаштовуваний клавіатурний виклик** — Ctrl+Space, Ctrl+Shift+Space, Ctrl+Alt+Space, Alt+Shift+Space, Ctrl+\` або вимкнено.
- **Дизайн** — колір акценту (синій, фіолетовий, зелений, бурштиновий, рожевий, монохром), оновлена темна тема, нова іконка. Підписи на колесі можна вимкнути.
- **Усі дії** — фільтр за типом, сортування за популярністю, кнопка запуску й лічильник запусків у кожному рядку.
- **Послідовності** (2.1) — групу можна позначити «Послідовність»: один вибір на колесі виконує всі її дії по черзі.
- **Гаряча клавіша меню** (2.1) — Ctrl+Alt+1…9 відкриває колесо одразу з потрібним меню.
- **Скасування** (2.1) — після видалення дії, групи чи меню кнопка «Скасувати» у сповіщенні повертає все як було.
- **Поділитися меню** (2.1) — одне меню зберігається у файл `.orbit-menu.json` і імпортується як нове, з новими ідентифікаторами.
- **Дублювання дії** (2.1) і **«Часті дії»** в меню іконки біля годинника.

## Встановлення

Запустіть `Orbit2-Setup-<версія>.exe`. Orbit 2 встановиться для поточного користувача в `%LOCALAPPDATA%\Programs\Orbit 2` без прав адміністратора, з ярликами «Orbit 2» на робочому столі й у меню «Пуск». Видалити можна в «Параметри → Програми». Портативна версія: розпакуйте `Orbit2-<версія>-win32-x64.zip` і запустіть `Orbit2.exe` з папки `Orbit2-win32-x64`.

Для розробки потрібні Windows x64, Node.js 22.12+ та системний .NET Framework 4.x:

```powershell
npm ci
npm run setup
npm start
```

Додатковий .NET SDK не потрібен: native-модуль компілюється системним C#-компілятором.

Іконка: редагований оригінал `assets/orbit.svg`, Windows-іконка `assets/orbit.ico` (16–256 px) і PNG-експорти. `npm run icons` відтворює растрові файли з SVG; `npm run package` також виконує цей крок і вбудовує іконку в `Orbit2.exe`.

## Як користуватися

- Бічна кнопка Mouse 4 відкриває колесо біля курсора. У «Керування» можна вибрати Mouse 5.
- Клавіатурний виклик — за замовчуванням **Ctrl + Space**, змінюється в «Керування».
- За замовчуванням затримайте курсор над дією для запуску; дуга навколо сектора показує, скільки лишилося. У «Керування» також є запуск відпусканням бічної кнопки або клацанням.
- Наведення на групу відкриває її вкладене колесо. Центр або праве клацання повертає на попередній рівень.
- **Esc** скасовує вибір і закриває колесо. У клавіатурному режимі: стрілки — вибір сектора, **Enter** — виконання, **Backspace** — назад, **1–9** — дія за номером.
- Сектор «+» на колесі додає програму, в якій ви зараз працюєте.
- У редакторі дії можна перетягувати: рядок на групу переносить дію в неї, сектор у попередньому перегляді змінює порядок, центр вкладеного кола переносить дію на рівень вище.
- Файли, папки й ярлики можна перетягнути у вікно з Провідника.
- Кнопка закриття згортає Orbit 2 у трей. Остаточний вихід — «Вийти з Orbit 2» у меню іконки біля годинника.

До кожного колеса можна додати до 12 дій; доступні до 20 окремих меню.

## Типи дій

| Тип | Дія |
|---|---|
| Застосунок | Запуск `.exe`, `.lnk`, застосунку з Microsoft Store або відкриття http(s)-посилання |
| Папка | Відкриття локальної директорії у Провіднику |
| Скрипт | Запуск `.ps1`, `.py`, `.js`, `.cjs` з аргументами |
| Windows | Провідник, диспетчер завдань, параметри, знімок екрана, звук, медіа, робочий стіл, блокування, команди вікон і робочих столів |
| Клавіші | Натискання комбінації клавіш у програмі під колесом |
| Текст | Вставлення заготовленого тексту через буфер обміну |
| Група | Вкладене радіальне меню |

## Дані

Налаштування зберігаються локально в `%APPDATA%\Orbit 2\settings.json` (формат версії 2; файли Orbit версії 1 імпортуються без змін). Статистика — у `usage.json`, щоденні копії — у папці `backups`. Є імпорт та експорт JSON. Програма не потребує облікового запису й нічого не надсилає.

## Оновлення

У «Налаштування → Оновлення» натисніть «Перевірити оновлення», потім «Завантажити» та «Установити й перезапустити». Orbit 2 отримує стабільні версії з репозиторію [Validolio11/Orbit-2](https://github.com/Validolio11/Orbit-2), перевіряє SHA-256 архіву, замінює файли окремим модулем після виходу й повертає попередню версію, якщо нова не запустилася. Меню й налаштування в AppData не замінюються.

### Публікація нової версії

GitHub Actions (`.github/workflows/release.yml`) на тег `v<версія>` запускає перевірки, створює `Orbit2-<версія>-win32-x64.zip`, інсталятор `Orbit2-Setup-<версія>.exe` і публікує GitHub Release. Версія тегу має збігатися з `package.json`. Локально: `npm run release`, потім `npm run installer`; файли з'являться у `release/`.

## Перевірка і збірка

```powershell
npm test
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-native.ps1
npm run smoke
npm run test:ui
npm run test:orbit2
npm run test:search
npm run package
```

`--e2e` та `--smoke-test` використовують окремі тимчасові налаштування. Запуск дій у цих режимах вимкнений; глобальний перехоплювач миші не встановлюється.

## Структура

- `src/main.cjs` — вікна, трей, IPC, запуск дій, збереження, меню для програм.
- `src/core.cjs` — перевірка налаштувань (версії 1 і 2), аргументи, геометрія колеса.
- `src/shortcuts.cjs` — комбінації клавіш для дій «Клавіші».
- `src/usage.cjs`, `src/backups.cjs`, `src/legacy.cjs` — статистика, резервні копії, перенесення з Orbit.
- `src/preload.cjs` — обмежений API між інтерфейсом і Windows.
- `src/renderer/` — редактор, колесо, огляд (`overview.mjs`), командна палітра (`palette.mjs`); `orbit2.css` — шар дизайну Orbit 2.
- `native/MouseHook.cs` — XBUTTON hook, Windows-команди, надсилання клавіш і watchdog процесу.
- `native/AdminTask.cs` — завдання Планувальника «Orbit 2 (administrator)» для запуску з правами адміністратора без запиту UAC.
- `docs/design.md` — рішення дизайну.
